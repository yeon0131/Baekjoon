## 🔽 입력 처리 팁: input() vs sys.stdin.readline()

- 기본적으로는 `input()` 사용으로 충분하지만,
- **입력 줄 수가 많거나**, **시간이 민감한 문제**에선 `sys.stdin.readline()`이 더 유리합니다.

### ✅ 요약 정리

| 상황 | 추천 함수 | 설명 |
|------|-----------|------|
| 입력 수 적고 일반적인 문제 | `input()` | 코드가 깔끔하고 직관적 |
| 수만~수십만 줄 입력 | `sys.stdin.readline()` + `.strip()` | 처리 속도 훨씬 빠름 |
| 느린 알고리즘 (예: O(N²)) 사용 | `sys.stdin.readline()` | 입력이라도 빠르게 해야 시간 초과 방지 가능 |

> 💡 **정리:**  
> - 간단한 문제 → `input()`  
> - 복잡하거나 대량 입력 문제 → `sys.stdin.readline().strip()`
